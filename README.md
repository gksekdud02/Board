# 📝 Board Service

Board Service는 **Spring Boot**와 **Thymeleaf**, **Spring Data JPA**를 사용하여 구현한 간단한 게시판 애플리케이션입니다.  
**MySQL**을 데이터베이스로 사용하며, **사용자 인증, 게시글 작성, 댓글 기능, 페이징, 검색, 수정/삭제 기능** 등을 포함하고 있습니다.

---

## 🚀 기술 스택
- **Backend** : Spring Boot, Spring MVC, Spring Data JPA, Spring Security, Spring Session
- **Frontend** : Thymeleaf, HTML, CSS, JavaScript
- **Database** : MySQL
- **빌드 도구** : Gradle

---

## 📌 주요 기능

### 1️⃣ 사용자 회원가입 및 로그인/로그아웃
#### ✅ 회원가입
- 사용자는 회원가입 페이지에서 **아이디, 비밀번호, 닉네임, 이메일** 정보를 입력
- **비밀번호와 확인 비밀번호가 일치하는지** 클라이언트와 서버에서 검증
- 닉네임 **중복 확인 기능**을 통해 닉네임 사용 가능 여부 실시간 체크

#### ✅ 로그인
- 사용자는 로그인 페이지에서 **아이디와 비밀번호 입력**
- **비밀번호 암호화 비교**를 통해 인증
- 로그인 성공 시 **사용자 정보를 HttpSession에 저장**하고 **메인 게시판 페이지로 이동**
- 로그인 실패 시 **오류 메시지 표시**

#### ✅ 로그아웃
- **로그아웃 버튼 클릭 시 세션 무효화** 후 메인 게시판 페이지로 리다이렉트

#### ✅ 버튼 표시 조건
- **로그인 상태에 따라 버튼 표시 조건 다르게 설정**
  - 로그인한 사용자가 있을 경우: **로그아웃 버튼 및 "내정보" 버튼 표시**
  - 로그인하지 않은 경우: **로그인/회원가입 버튼 표시**

---

### 2️⃣ 게시판 기능
#### ✅ 게시판 목록 조회
- **게시글 번호, 제목, 작성자, 작성일, 조회수** 표시
- **검색 기능 추가**: 제목 또는 작성자로 게시글 검색 가능
- **페이징 기능 추가**: 한 페이지당 10개 게시글 표시

#### ✅ 게시글 최신순 정렬 및 번호 표시
- 게시글은 **최신 글이 가장 위에 오도록 내림차순 정렬**
- **번호는 최신 글이 1번이 되도록 표시**

#### ✅ 게시글 상세보기
- 글을 클릭하면 **제목, 작성자, 작성일, 댓글, 게시글 내용 표시**
- **로그인한 상태 & 작성자 본인일 경우 수정/삭제 버튼 활성화**
- **조회수 증가 기능 추가**

#### ✅ 게시글 작성
- **로그인한 사용자만 글쓰기 가능**
- 로그인한 경우: **글쓰기 버튼 클릭 시 /board/writePage로 이동**
- 로그인하지 않은 경우: **팝업 메시지("로그인이 필요합니다.") 후 로그인 페이지(/auth/login)로 이동**

#### ✅ 게시글 수정
- **본인이 작성한 글만 수정 가능**
- 수정 페이지에서 제목과 내용을 변경 후 저장 가능

#### ✅ 게시글 삭제
- **본인이 작성한 글만 삭제 가능**
- 삭제 버튼 클릭 시 **삭제 확인 팝업**이 뜨고, 확인 시 삭제됨

---

### 3️⃣ 댓글 기능
- 게시글에 달린 **댓글을 조회, 작성 가능**
- **본인 댓글만 삭제 가능**
- 댓글 작성 후 **자동으로 해당 게시글 페이지로 이동**

---

### 4️⃣ 페이징 및 검색 기능
#### ✅ 페이징 처리
- 한 페이지당 **10개씩 게시글 표시**
- `처음`, `이전`, `다음`, `마지막` 버튼 추가
- 선택한 페이지는 강조 표시

#### ✅ 검색 기능
- 제목 또는 작성자로 게시글 검색 가능
- 검색 결과도 **페이징 적용**

---

### 5️⃣ 사용자 정보 관리 (내정보 페이지 추가)
- **내정보 페이지에서 본인이 작성한 게시글 목록 조회 가능**
- **비밀번호 변경 기능 추가**
- **닉네임 변경 기능 추가**
- **회원 탈퇴 가능 (DB에서 삭제 또는 상태 변경)**

## 📌 API Endpoints
### 🔹 Auth 관련
| 메서드 | URL | 설명 |
|--------|------|------|
| `GET` | `/auth/signup` | 회원가입 페이지 반환 |
| `GET` | `/auth/login` | 로그인 페이지 반환 |
| `POST` | `/auth/register` | 회원가입 처리 |
| `POST` | `/auth/signin` | 사용자 로그인 처리 |
| `GET` | `/auth/logout` | 사용자 로그아웃 처리 |
| `GET` | `/auth/checkNickname` | 닉네임 중복 확인 (AJAX) |

---

### 🔹 Board 관련
| 메서드 | URL | 설명 |
|--------|------|------|
| `GET` | `/board/` | 게시판 메인 페이지 반환 |
| `GET` | `/board/writePage` | 게시글 작성 페이지 반환 |
| `POST` | `/board/write` | 게시글 작성 기능 |
| `GET` | `/board/{id}` | 게시글 상세보기 |
| `POST` | `/board/{id}/delete` | 게시글 삭제 기능 |
| `PUT` | `/board/{id}/edit` | 게시글 수정 기능 |
| `GET` | `/board/search` | 제목 또는 작성자로 게시글 검색 |
